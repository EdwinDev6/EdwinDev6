<h3>About me</h3>

<img align="right" alt="dev" src="images/81178b47a8598f0c81c4799f2cdd4057.gif" width="300" height="300"/>

<p>
Frontend Developer at a <b>banking institution</b>, building the interfaces behind critical financial operations: digital onboarding flows, credit and loan simulators, and internal platforms used every day.<br><br>

My day-to-day stack is <b>React, Next.js (App Router) and TypeScript</b>, with <b>TanStack Query</b> for server state, <b>Zustand</b> for client state, and <b>MUI</b> for UI.<br><br>

I'm building a company-wide <b>Design System</b> on top of MUI: wrapped components, theming, a Turborepo monorepo, tsup builds, Storybook docs, and distribution through a private package registry.<br><br>

I care about clean architecture: business logic in <b>custom hooks</b> and <b>pure, testable utilities</b>, typed API contracts, and a clear split between frontend calculations and backend-driven data.<br><br>

Working in finance means security and reliability come first: authentication flows, session handling, OTP verification and integration with APIs exposed through <b>Azure API Management</b>.<br><br>

Outside the bank, I run <a href="https://nuvixweb-landing-page.vercel.app"><b>NuvixWeb</b></a>, my own web development brand, and I'm finishing my university degree.
</p>
